### 工程治理（2026-11-06）

- 补齐 agent 基础设施：新增 `AGENTS.md`（工作规则、质量门、领域事实、已知坑）与 `docs/agents/` 三件套
  （issue-tracker / triage-labels / domain）。
- 修复 CI 从未成功运行的问题：`package-lock.json` 长期被 `.git/info/exclude` 排除，而 CI 的
  `cache: npm` 与 `npm ci` 都依赖它。现已纳入版本控制，CI 首次全绿（run `42234877441`）。
- 修复 `ShareableReportModal` 生成时间断言的时区依赖：测试硬编码了 UTC+8 的结果，导致 CI（UTC）
  渲染为 01:30 而失败。改为由同一套本地格式化逻辑推导期望值，断言与运行时区无关。
- CI 触发分支从仅 `main` 改为 `['**']`，feature 分支的推送同样会被验证。
- 新增 `format:check` 到 CI，并完成一次全仓格式化（`src` 51 个文件）。`docs/archive/` 经
  `.prettierignore` 排除，历史文档不做格式改写。
- 修复 `.gitignore` 与 `.git/info/exclude` 中未锚定的 `build/` 规则：该规则会连带忽略
  `scripts/build/`，导致 `scripts/build/BUILD_SCRIPTS.md` 长期无法入库且 `git status` 不可见。
  现改为 `/build/` 只匹配根目录。
- 修正 `package.json` 中 `repository` / `bugs` / `homepage` 的占位地址 `your-username`，
  改为实际仓库 `Qsd6917/DLUT_GPA`。
- README 的一键启动说明同时给出 `一键启动.bat` 与 `scripts/start-dev.ps1` 两种等价方式，
  并注明改动启动流程需同步维护两者。`一键启动.bat` 经用户决定保留，未移除。
- 在 GitHub 仓库创建 `needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`
  四个 triage 标签（`wontfix` 为 GitHub 默认自带）。

  `wcag-contrast` 包，不依赖此文件。`utils` 覆盖率 78.14% → 99.28%。
- 新增 4 个测试文件、42 个用例，测试总数 171 → 213：
  - `LanguageContext.test.tsx`（7 例）：语言切换、文案完整性、位置参数替换、Provider 外抛错。
    该 Provider **没有 localStorage 持久化**（只有 `useState<Language>('zh')`），因此「持久化」
    与「无效值回退」两条写成锁定当前行为的 tripwire 用例，注释已说明将来补上持久化时需改断言。
  - `ConfirmDialog.test.tsx`（14 例）：焦点进入/恢复、Tab 困焦、Escape、滚动锁、回调更新。
  - `ReloadPrompt.test.tsx`（6 例）：mock `virtual:pwa-register/react` 虚拟模块（测试文件内
    `vi.hoisted` + `vi.mock`，无需改共享配置），覆盖离线就绪/需刷新/关闭/回调透传。
  - `Header.test.tsx`（15 例）：分区切换、主题与语言、下拉 roving 键盘、移动端工具面板。
- 全项目覆盖率：88.29% → 89.92% statements，78.48% → 80.03% branches，69.33% → 74.55% functions。
- `LoadingContext.tsx` 仍为 56.92%，是当前唯一低于 80% 的模块，列为后续补测目标。

### 新增功能

- 新增目标成绩规划器，在“快速估算”和“逐课规划”之间切换；未来课程可分别选择自动规划或固定百分制分数。
- 逐课规划覆盖现有六种 GPA 算法；存在自动课程时，以 `0.1` 分刻度给出不低估达标要求的最低均衡分数，并展示预计或最高可达 GPA。
- 目标规划标签页支持方向键、Home、End 键导航，并提供当前值、目标值、预计值与算法上限的可访问刻度。
- 实现了代码分割和懒加载功能
- 添加了虚拟滚动以优化大量课程数据的性能
- 集成了防抖功能优化搜索体验
- 创建了全局加载状态指示器
- 新增了 LoadingContext 状态管理器

### 改进

- 目标规划统一使用全部计入 GPA 的课程，不受搜索、学期、类型或核心课程筛选影响；实验进行中则自动跟随实验草稿。
- 逐课规划保持为本地内存草稿，不写入正式课程或浏览器持久化数据。
- 将 GPA 仿真与沙盒入口统一为实验室：实验草稿与正式课程隔离，只有“应用到正式数据”才会持久化；总览首屏移除重复摘要条，并统一中英文界面文案。
- 优化了 AIAdvisorPanel 组件性能
- 改进了 CourseList 组件渲染效率
- 升级了搜索功能，提供更流畅的用户体验
- 增强了应用的整体性能和响应速度

### 修复

- 补强逐课规划的有限数与汇总溢出校验，并拒绝空 ID 或重复课程 ID，避免结果关联错误。
- 为每个规划器实例生成独立 ARIA 标识，避免同页多实例的标签页、面板和错误提示发生 ID 冲突。
- 切换快速估算与逐课规划时保留各自输入状态，并保持目标规划器懒加载边界。
- 统一 WES 算法的界面标签与实际计算口径，明确显示为 WES 4.0。
- 修复了课程过滤时的性能问题
- 解决了大量数据渲染卡顿的问题
